# STAR MERCHANT

다섯 행성을 여행하며 상품을 사고파는 작은 우주 무역 게임입니다. 한국어 UI와 모바일 화면을 지원합니다.

[웹에서 바로 플레이](https://damyo-zip.github.io/star-merchant/)

## 실행

이 저장소의 `index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 서버, 빌드, 패키지 설치, 외부 폰트나 서비스가 필요하지 않습니다. HTML과 함께 `styles.css`, `game.js`, `ui.js`를 같은 폴더에 두세요.

## 플레이 방법

- 초기 자금은 **1,000크레딧**, 화물칸은 **20개**입니다.
- 에너지 수정(◇), 티타늄 합금(▱), 성운 향신료(✳)를 거래합니다. 모든 상품은 개당 화물칸 1개를 차지합니다.
- 시장에서 수량을 입력하거나 − / +로 조절하고 구매·판매를 누르세요. 버튼에 거래 총액이 표시됩니다. 잔액, 화물 한도, 보유 수량을 넘는 거래와 잘못된 수량은 거절됩니다.
- 모바일에서는 하단의 **시장·항로·의뢰·함선** 버튼으로 화면을 전환합니다. 자금과 화물칸은 스크롤 중에도 상단에 표시됩니다. `최대`는 잔액과 남은 화물칸으로 구매 가능한 최대 수량, `전량`은 보유한 판매 수량을 선택합니다. 선택 후 구매·판매 버튼을 눌러 거래하세요.
- 행성 항로에서 다른 행성을 누르면 **무료로 이동**하고 1턴이 지납니다. 각 행성 카드에 표시된 세 상품의 현재 시세를 비교하세요. 모바일에서는 다섯 행성을 세로 목록으로 확인하며, 이동 후 도착한 행성의 시장이 열립니다.
- 여행할 때 모든 행성의 일반 가격이 각 기준가의 **±25%** 범위에서 다시 정해집니다. 특별 시세 대상에는 추가 배수가 적용되며 최종 가격은 정수로 반올림합니다. 출발 전 시세와 도착 후 시세는 다를 수 있습니다. 구매·판매는 턴을 소모하지 않습니다.
- **총자산 = 현금 + 현재 행성 시세로 평가한 화물 가치**입니다. 거래 또는 여행 후 총자산 **10,000크레딧 이상**이면 승리합니다. 승리 후에도 플레이할 수 있습니다.
- 테라에서 시작합니다. 수정이 저렴한 베스퍼, 합금이 저렴한 아레스, 향신료가 저렴한 네레아를 찾아 다른 행성에 판매해 보세요.
- `새 게임`은 확인 후 초기화합니다. 진행 상황 자동 저장은 없으며 새로고침하면 새 게임이 시작됩니다. 최단 승리 기록만 같은 브라우저에 저장됩니다.

## v1.1: 항해마다 새로운 선택

### 배송 의뢰 — 짧은 목표와 추가 보상

의뢰 게시판에서 상품·목적지·납품금을 비교해 한 건을 수락하세요. 직접 구매한 상품을 운송하고 목적지의 의뢰 화면에서 **납품하고 보상 받기**를 누릅니다. 납품금은 상품 대금과 240~300 C의 추가 보상을 합친 고정 금액으로, 수락 후 시장 가격이 바뀌어도 유지됩니다. 시장에 일반 판매한 화물은 의뢰 납품으로 처리되지 않습니다.

수락한 항해 번호에서 **4번의 여행까지** 납품할 수 있습니다. 예를 들어 항해 0에서 수락하면 항해 4까지 가능하고, 항해 5에 만료됩니다. 수락·구매·납품은 턴을 소모하지 않습니다. 만료하거나 포기해도 위약금은 없고 화물은 유지됩니다. 의뢰 게시판은 여행마다 갱신됩니다.

첫 의뢰는 테라에서 에너지 수정 4개를 구매해 아레스에 납품하는 짧은 항로입니다. 보상으로 번 자금을 모아 함선을 확장하거나 더 큰 교역에 투자해 보세요.

### 특별 시세 — 준비하고 항로 바꾸기

시장 소식에서 다음 이벤트의 행성·상품·시작 시점을 미리 확인할 수 있습니다. **수요 급증은 가격 ×1.7**, **과잉 공급은 가격 ×0.55**입니다. 첫 이벤트는 항해 2~3에 유지되고, 이후 5~6, 8~9처럼 3항해 간격으로 새 기회가 생깁니다. 대상과 종류는 매번 무작위입니다. 해당 상품 이외에는 일반 시세가 적용됩니다.

저렴해질 상품을 구매하러 갈지, 급등할 시장에 화물을 미리 준비할지 선택하세요. 의뢰 납품금보다 시장 판매가 유리한 경우도 있으므로 시세와 보상을 함께 비교하세요.

### 함선 확장 — 지금의 자금과 다음 거래의 규모

함선 화면에서 **20 → 25칸은 1,200 C**, **25 → 30칸은 2,000 C**로 확장할 수 있습니다. 확장비는 총자산에서 차감되며 함선의 가치는 자산에 포함하지 않습니다. 다음 거래가 막히지 않도록 확장 후 **100 C 이상의 거래 자금**이 남아야 합니다. 확장은 선택 사항이며 승리에 필수는 아닙니다.

### 손익과 최단 기록 — 결과를 확인하고 다시 도전

매입 원가를 추적해 선택 수량의 예상 판매 손익과 누적 거래 손익을 표시합니다. 여러 가격으로 매입한 화물은 합산 원가를 수량 비율로 배분하고 반올림하며, 마지막 판매·납품에서 남은 원가를 모두 정산합니다. 납품금은 거래 손익에 포함되고 확장비는 제외됩니다.

최초 승리한 항해 수를 기록합니다. 승리 후 계속 플레이해도 기록은 바뀌지 않으며, 새 게임에서 더 짧은 항로에 도전할 수 있습니다. 기록은 브라우저의 `localStorage`에만 보관하며, 저장을 허용하지 않는 브라우저에서도 게임은 정상 실행됩니다.

## 코드 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 및 스크립트 로딩 |
| `styles.css` | 레트로 SF 스타일, 모바일 반응형 레이아웃 |
| `game.js` | DOM에 의존하지 않는 경제 로직 및 상태 전환 |
| `ui.js` | 화면 렌더링, 입력 처리, 거래 피드백 |
| `tests/game.test.cjs` | 경제 규칙 자동 테스트 |

경제 함수는 기존 상태를 수정하지 않고 결과 상태를 반환합니다. 가격 난수 함수를 주입할 수 있어 테스트가 재현 가능합니다. 브라우저에서는 일반 스크립트를 사용하므로 `file://`로도 실행됩니다.

## 자동 테스트

테스트에만 Node.js 18 이상이 필요합니다. 별도 의존성은 없습니다. 저장소 루트에서 실행하세요.

```sh
node --test tests/game.test.cjs
```

초기 상태, 구매·판매 정산, 잔액과 화물 한도, 여행 및 시장 갱신, 자산 평가, 의뢰 기한·납품·중복 보상 방지, 확장과 예비 자금, 매입 원가·부분 판매 손익, 예고된 이벤트의 시작·종료, 승리와 항해 기록을 검증합니다. 배송 → 확장 → 교역 → 승리까지 이어지는 플레이도 포함합니다.
